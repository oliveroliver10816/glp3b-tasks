How to do it

Search Console → URL Inspection → paste the URL → Request Indexing. Copy each one with the button, work down the list, and stop when Google refuses — there is a daily limit per property and it is small.

Never submit the same URL twice. Google states plainly that requesting a recrawl more than once for the same URL will not get it crawled any faster.
